# Web 聊天与设置交互

聊天输入区按会话自动保留文本、附件和计划模式，切换会话或临时打开项目页后可继续编辑。暂存状态保存在当前页面内存中；退出登录或刷新页面会清除，不显示单独的草稿按钮。

发送中的内容和编辑区分开。发送失败后保留完整发送记录，支持重试；编辑区为空时可以将失败内容恢复编辑。生成期间 Enter 不会停止任务，停止通过明确的停止按钮执行。中文输入法确认候选词不会发送消息。

统一使用 Agent 交互，不再区分 Chat/Agent 模式。侧栏按项目 ID 分组，无项目 ID 的旧会话按目录匹配，未知目录独立成组。旧 Chat 会话和 Agent 会话一起展示，浏览器中的旧模式标记不再参与筛选。模型选择仍在输入区右下方，工作目录在会话标题下一行显示。

## 历史与流式输出

- 首次显示历史时定位到最新内容；回访会话恢复当前页面中记住的阅读位置。
- 上滚阅读历史时暂停自动跟随，使用“回到最新”恢复；待确认的问题和权限有固定入口。
- 初次渲染最近 40 组消息，可继续加载更早内容，加载时保持阅读锚点。当前接口仍读取完整历史，后端游标分页属于后续独立优化。
- Markdown 按文本块复用渲染结果，只处理变化的块；流式更新合并到约 32ms 的渲染间隔，结束时立即显示最终内容。
- 历史消息可先于辅助状态显示，辅助请求失败提供重试。HTTP 错误不会当作空历史。

## 文件变更与计划参考

会话标题栏的「变更」打开只读快照审阅面板，按文件展开变更前后内容与增删行数。面板固定请求所属会话目录，切换会话时清除旧快照，迟到响应不能覆盖新会话；刷新失败保留上次快照并允许重试。运行结束会尝试刷新，收到当前会话的 `session.diff` 持久化完成事件后再次更新，全局事件流首次连接和重连时也重新读取快照；实时更新中断时显示提示，并保留手动刷新。审阅对话框挂载到视口级遮罩，避免侧栏或预览栏裁剪关闭和刷新操作。打开搜索前会关闭变更对话框，防止下层焦点锁干扰搜索。它读取已有 session diff，不执行暂存、提交或回退；快照可能包含会话期间的其他工作区操作，并不保证全是 Agent 独占修改。空列表也不等于已验证工作区无改动。

「先规划」当前是提示词引导，没有提供只读工具沙箱或强制审批状态机。界面明确说明这一点；「计划参考」只是从回复提取的候选内容，不表示计划已批准。完整结构化审批、hunk 回退与测试验收状态属于后续独立功能。

## 设置

桌面采用分类侧栏，移动端采用目录与二级页面。模型选择和供应商认证位于同一分类。模型列表支持搜索，优先展示已连接供应商，分批显示结果。

打开设置只读取当前分类，不写回供应商配置。短时间切换模型与供应商子页复用读取结果，可手动刷新。设置的异步组件也按访问需要加载。

保存失败会展示错误并保留输入。API Key 和 MCP 表单在服务端确认成功后才清空；切换分类保留未保存字段。关闭有未保存修改的设置时需要确认。模态对话框支持 Escape、Tab 焦点限制与关闭后的焦点返回。

## 验证

```sh
bun test web/test
bun run --cwd web typecheck
bun run --cwd web build
```

浏览器回归应覆盖：发送创建期间切换会话、A→B→A 草稿恢复、发送失败后继续编辑、附件上传期间切换、输入法 Enter、长历史首载与上滚、快速选择模型/平台、设置保存 500、未保存表单切页、Escape/Tab 和 390px 移动布局。

开发服务器默认代理到 `http://127.0.0.1:4096`。需要其他后端地址时，在启动 Vite 前设置 `NINE1BOT_API_ORIGIN`。生产构建通过 Nine1Bot 服务直接提供页面。
