## 已实现

### 参数纠错

- CI、仓库工具的描述、校验错误和审查提示词提供带数字类型的 JSON 示例。
- 继续拒绝字符串数字、越界数字、额外字段等输入，不自动转换或绕过 schema。
- 提示模型最多纠正一次，仍失败则说明证据缺口并继续审查。这是模型引导，不是新的执行层重试配额。
- 未关联到具体 diff 缺陷的 CI 失败只能进入摘要或后续行动，不能直接作为代码 finding。

### 冻结源码缓存

- 进程内缓存仅复用完整文件，按 run/session/generation、仓库、冻结 SHA、API 地址及凭证摘要隔离，不落盘，不保存 token 明文。
- 每组最多 48 个文件、2 MiB；缓存表最多 16 组，10 分钟未使用及终态组在下次访问时清理，满容量淘汰最久未访问组。
- 搜索与片段读取复用完整 blob，截断响应不缓存。并发未命中仍独立计费，不共享其他调用的取消信号。
- 命中缓存仍检查路径策略、配置、凭证、取消和当前 attempt，并消耗查询与输出预算；仅避免重复网络下载计费。
- 不提高原有 API、文件、字节、查询或输出额度；额度耗尽时提示停止继续取证。

### 有限格式恢复

- 只在会话成功结束、没有有效结果、原 run 仍 running 且 session/generation 未变时，允许一次原会话格式纠正。
- 保留原模型、agent、历史及权限，所有工具关闭，包括 task；不创建新 review attempt，不重置总超时预算，不追加新 diff。
- 纠正失败按原失败路径结束，正常运行失败、发布失败和策略拒绝不触发格式纠正。
- 不从混合文本中提取“看起来像结果”的片段；继续要求唯一、完整、严格的结果块。
- monitor 等待已收到的输出回调完成，再处理结束事件。发布移到会话结束之后，避免流式合法前缀提前触发发布。

## 回归覆盖

- 数字参数拒绝、明确提示、正确参数成功进入检查器。
- 同一冻结文件跨搜索与读取复用，跨会话隔离，截断文件重新下载，终态、取消、缺失凭证和凭证轮换不越界命中。
- 一次格式纠正成功后仅发布一条摘要；再次无效则失败，不无限重试。
- 纠正时全部工具禁用、原 session/generation 保持不变、剩余超时不增加。
- 流式合法前缀后追加文字不能提前发布；结束回调等待未完成的输出处理。
- monitor 回归加入运行时 CI。

本地验证结果：GitLab/review 与 CI 契约测试 423 项通过；运行时 CI 257 项及独立 registry 1 项通过；补充迟到回调隔离后，webhook/monitor 39 项复测通过。Nine1Bot 与 OpenCode 类型检查均通过。

## 待验证

本次只修改本地代码并执行自动化测试，尚未部署到联调服务器。下一次真实 Qwen 联调需确认数字参数纠错效果、CI 日志读取、缓存计费和最终发布；提示词无法保证任意模型始终遵守协议，自动化通过不能替代该验证。
